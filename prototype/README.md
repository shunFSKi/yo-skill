# yo-skill 桌面端 UI 原型（7 屏）

产品设计 V2（见 `mavis-deep-research/20260811_161937_yoskill_product_design/`）的高保真静态原型。纯 HTML/CSS，无构建、无依赖（字体走 Google Fonts CDN，离线时回退系统字体）。

## 打开方式

直接双击任意 HTML 文件，或从 `index.html` 开始进入、页内链接互相跳转。`onboarding.html` / `restore.html` 是两个独立全屏向导（无侧栏），流程终点都回到 `index.html`。

`yo.css` 是共享设计系统（E 墨极黑白骨架 + 翡翠/绿/红功能色 + 琥珀橙提醒，成功徽章中性化，含深色模式；Agent 标签条用 7 品牌色瓷砖，条目图标另有一层 8 色内容识别色按名称哈希着色，均与功能语义色分层；尾部为向导两屏共用的 `.ob-*` 组件：居中窄栏 / 步骤点 / 扫描动画 / 统计卡，进度条与成功勾复用安装卡组件）；`yo.js` 管浅/深切换（侧栏底部按钮，localStorage 记忆，默认跟随系统，亦可用 `?mode=dark` 直达）与条目图标哈希着色；`yo-dedupe.js` 管重复项演示状态（组注册表 + 合并/三选一/保持现状持久化，dedupe 页与主屏提醒条共用，跨标签页 storage 事件同步）；`logos/` 是主流 Agent 官方品牌 SVG（simple-icons + 各官网/官方仓库，本地引用无依赖；瓷砖墙的纯黑 logo 已内联进 HTML 以 currentColor 着色，Roo Code 用官方字标裁出的袋鼠图标，迷你档仍引用文件、深色自动反白）；`shots/` 是 1440×900 验收截图（主屏含统一视图与按助手看两态，发现页另含 MCP 分段 / 安装弹层 / 条目详情，设置页另含同步与 Key 分区，重复项页另含已处理态，向导两屏含发现结果 / 云同步恢复码 / 恢复清单，+ 主题对比 + 状态配色对比）。

## 公开官网（已迁入 `apps/web`）

官网不再是静态原型：2026-08-13 第四轮在 `web/` 重建的「纸上墨字 + 一笔翡翠」静态稿被用户否决形态（"怎么还是静态啊，项目里面不是有 web 项目吗？还有不要放桌面端截图"），同日将该设计语言平移进项目自带的 Next.js 官网 **`apps/web`**，本目录下的 `web/` 已删除。当前官网的配色 / 笔触 / bento 结构 / 文案口径见 `apps/web/README.md`。

历史教训（沿用）：① 参考竞品只取底层手法（排印力度 / 节奏 / 色彩自信），身份识别元素必须从自有品牌（E 墨极：纸面墨字 + 一笔翡翠）长出来——第三轮曾因整套照搬 cindy.app 招牌元素（mono 编号 / marquee / ghost 水印 / crosshair / 黑段顶边线卡）被整目录删除；② 官网不摆放桌面端截图，产品一律以活组件预览呈现；③ 官网代码归 `apps/web`，`prototype/` 只做桌面端设计稿。发现站与详情页未做，记入下一轮。

## 设计依据

- 视觉世界：品类标准（1Password 信息架构 × Raycast 单一入口 × Linear 精致度），决策过程与完整规则见根目录 `DESIGN.md`、`PRODUCT.md`
- 所有条目为**演示数据**（每页页脚有标注）；向导两屏的扫描/收拢/恢复过程均为演示动画，不写 localStorage
- 界面术语：AI 助手 / Skill / MCP / API Key，导航为 已安装 / 发现（2026-08-11 起弃用 大脑/工具箱/保险库/钥匙 隐喻）
