# Happycapy（https://happycapy.ai/）
- 定位一句话：面向大众的云端 agent-native 电脑，把 frontier models、skills 与自动化沙盒集成在一个聊天入口里。
- 商业模式：Freemium 订阅 + 积分消耗。Free $0/月（250 credits，基础 sandbox）；Pro $20/月（$17 年付，2000 credits，frontier models）；Plus $50/月（$42 年付，5000 credits）；Max $200/月（$167 年付，22000 credits，agent teams GUI）。另售 Team 与企业版。

## 首屏
- 导航结构：Logo（左侧）+ Skill Store / Pricing / Use Cases / Tools（中部）+ Log in / Start free（右侧）。无汉堡菜单，桌面端平铺。
- 主标题原文：Your agent-native computer
- 副文案：Where frontier models, skills, and automations work together to get things done.
- CTA：首屏核心 CTA 是一个居中的自然语言输入框，占位文案循环打字（如 Email me a tech news digest every m / Find a skill that sc），下方有一排 action chip：Research / Generate image / Generate video / Create slides / Create skill / Frontend design / Capymail skill。右上角 "Start free" 为实心黑底按钮。
- 视觉形式：产品界面截图式 hero，背景为极浅灰/米白，无插画；输入框下方直接展示技能卡片轮播（Build websites / Research / Generate videos 等分类），让首页看起来像可直接交互的 app 橱窗。

## 区块结构（自上而下）
1. Hero：居中标题 + 动态输入框 + action chips + 分类 skill 卡片轮播。
2. Model wall：The right model for every task. Zero setup.——一长串模型 logo/名称 marquee（Fable、Seedream、Opus、Nano Banana、GPT-5.6、Kimi K3、Grok 等），强调一订阅覆盖多模型。
3. Sandbox 卖点：Your agents work in an isolated sandbox，四格小卡片（Secure & isolated / Runs 24/7 / Built for automation / You're in control），右侧配一个运行中的任务卡片（Weekly revenue report / Running）。
4. 数据墙：Happycapy by the numbers——20+ frontier models / 2M+ skills / 200+ countries & regions。
5. 团队协作：Kick start every task with your team。
6. 底部 CTA：Ready to start your first project? + Get started for free。
7. Footer：© 2026 Happycapy，分 Product / Resources / Company 三栏。

## 配色与气质
- 主色：米白/极浅灰背景（接近 #FAFAF8），文字几乎纯黑，按钮黑底白字（Start free）。
- 辅色：skill 卡片封面使用高饱和摄影/生成图（花卉、蓝天、UI 截图），为页面提供色彩；UI 控件用细灰边框、圆角较大。
- 字体气质：标题使用衬线体（类似 Times / Source Serif），正文无衬线，整体偏「温暖、人文、不极客」；与典型 AI 工具站的黑体科技感拉开距离。
- 信息密度：中高。首屏没有大段文字，靠输入框、chip、卡片轮播直接展示功能。

## 转化路径
- 落地即见输入框，鼓励用户立即用自然语言尝试任务；
- 顶部 "Start free" 常驻；
- 向下滚动后，模型墙与 sandbox 卖点建立信任；
- 底部再次强调 "Get started for free"，进入注册。

## 值得抄
- **动态占位文案输入框**：把 hero 变成一个可直接感知的 command bar，占位文案循环演示真实任务，降低「这是什么东西」的认知成本。yo-skill 的官网 hero 可以借鉴：占位文案切换展示「把 Claude 的 skill 同步到 Cursor」「帮我找能写 PRD 的 skill」。
- **Action chips 即场景标签**：输入框下方不是传统 feature list，而是一排可点击的场景 pill，让用户瞬间知道能做什么。
- **分类 skill 橱窗轮播**：首屏下半部分直接展示 skill store 的封面卡片，把「商城」前置到首页，而不是只放介绍。

## 不值得抄 / 对我们不适用
- 云端电脑 + sandbox 是 Happycapy 的核心产品，yo-skill 不做云端 runtime，因此「模型墙」「sandbox 卖点」整块叙事不能照搬。
- 输入框的即时执行幻觉（实际并不会在官网直接运行任务）可能给用户过高预期，yo-skill 作为本地同步工具，hero 输入框更适合用于「搜索/发现 skill」而非「直接运行 agent」。
