# PulseMCP（https://www.pulsemcp.com/）

- 定位一句话：MCP 生态的资讯与目录门户，以 newsletter「The Agentic Loop」为核心抓手，帮助用户「跟上 MCP 的变化速度」。
- 商业模式：免费内容/目录 + newsletter 订阅 + 可能的咨询/合作（「Work With Us」）。未看到订阅付费或付费墙。

## 首屏（导航结构 / 主标题原文 / 副文案 / CTA 文案与层级 / 视觉形式：产品截图？插画？纯排版？）

- 导航结构：顶部 Logo「pulse」+ MCP Servers / MCP Apps / Posts / Work With Us / THE AGENTIC LOOP（newsletter 按钮）。
- 主标题原文：H1「Explore the Model Context Protocol」。
- 副文案：「Everything MCP: servers, clients, use cases, tools, and The Agentic Loop newsletter」。
- CTA：邮箱输入框 + 紫色按钮「Subscribe to The Agentic Loop」，是最强行动号召；次 CTA 是导航中的 MCP Servers / MCP Apps。
- 视觉形式：左右分栏 hero，左侧纯排版，右侧是一幅手绘风格的心电图/波形插画（紫色主线 + 橙色节点），无产品截图。

## 区块结构（自上而下逐区块列出）

1. 顶部紫色通知条：「Quick heads up! New server submissions and listing changes are paused until mid-August while we rework our ingestion and listing management processes. Thanks for your patience! More details」。
2. Hero 区：左文右图 + 邮件订阅。
3. 「What'll it be today?」：4 张大入口卡片——MCP Servers / MCP Clients / Pulse Posts / Use Cases，每张带手绘插画与一句话说明。
4. 「MCP Moves Fast. Stay Current Here.」：再次放置邮件订阅，强化 newsletter 转化。
5. 「Who's behind Pulse?」：两位创始人/维护者头像与简介，建立信任。
6. 「You might find interesting」：精选文章/资源卡片。
7. 「Why MCP Matters」：深色底教育区，用「Just as HTTP standardized web communications, MCP creates a universal protocol…」做类比。
8. 「Official MCP Resources」：官方资源链接区（截图未完全展示）。

## 配色与气质（主色 / 底色 / 深浅 / 字体气质 / 信息密度，必须来自截图实看）

- 主色：大面积纯白底，心电图/波形用紫色（#6B4EE6 左右），通知条同色系，点缀橙色小节点。
- 底色：暖白/浅灰白，卡片纯白，「Why MCP Matters」区反转为深黑底。
- 深浅：默认浅色模式，无明显的深色切换按钮可见。
- 字体气质：标题使用衬线体（类似 DM Serif / Playfair），正文无衬线，整体偏人文、编辑感、杂志气质。
- 信息密度：低。留白极大，每屏 1-2 个区块，阅读节奏舒缓，更像内容门户而非工具商店。

## 转化路径（落地 → 下载 / 安装 / 注册 / 浏览 的路径设计）

- 落地即被引导订阅 newsletter：hero 区邮箱输入 +「MCP Moves Fast」区再次订阅。
- 浏览目录：通过「MCP Servers」「MCP Apps」导航或「What'll it be today?」入口卡片进入。
- 学习：通过 Posts / Use Cases / You might find interesting / Why MCP Matters 逐步建立认知。
- 信任：「Who's behind Pulse?」展示 MCP Steering Committee 成员背景，强化权威性。

## 值得抄（具体到组件与手法，如"hero 把 CLI 命令做成可点击复制的芯片"，禁止"简洁大气"这类空话）

- **手绘心电图/波形插画**：把抽象的「Pulse」概念视觉化成品牌符号，记忆点强，适合 yo-skill 围绕「同步/跨电脑」做类似隐喻插画。
- **创始人背书区**：「Who's behind Pulse?」用真人头像 + 轻松文案建立可信度，独立开发者产品可借鉴。
- **「Why MCP Matters」类比教育区**：用 HTTP 类比 MCP，一句话讲清协议价值；yo-skill 可用类似手法解释「为什么需要统一管理 Skill/MCP」。
- **邮件订阅作为核心 CTA**：对尚在产品早期的项目，newsletter 订阅是比「立即下载」更轻的转化路径。
- **4 大入口卡片**：Servers / Clients / Posts / Use Cases 把复杂生态做成 4 个可点击大色块，降低小白选择成本。

## 不值得抄 / 对我们不适用

- 顶部紫色通知条：占首屏宝贵空间，且内容与 yo-skill 产品价值无关。
- 信息密度过低：目录内容不直接展示，用户需多次点击才能看到 servers， yo-skill 官网若主打「发现」应更直接。
- 术语门槛高：「Model Context Protocol」「Agentic Loop」对目标小白用户不够友好， yo-skill 应避免此类硬核术语。
- 过重的内容/编辑气质：PulseMCP 更像媒体门户， yo-skill 是工具产品，官网应更突出「管理、同步、安装」的行动感。
