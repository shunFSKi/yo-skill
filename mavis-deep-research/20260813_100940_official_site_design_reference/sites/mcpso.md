# MCP.so（https://mcp.so/）

- 定位一句话：面向 MCP 生态的轻量 Marketplace，聚合 servers、clients、CLI tools、loops、agent skills，以「发现本周热门」为核心入口。
- 商业模式：免费目录 + 广告/赞助变现。顶部有 sponsor banner（ShipAny），首页有「Sponsors」卡位与「Advertise」入口；未看到订阅或付费墙。

## 首屏（导航结构 / 主标题原文 / 副文案 / CTA 文案与层级 / 视觉形式：产品截图？插画？纯排版？）

- 导航结构：顶部 Logo「MCP.so」+ 搜索框（占位「Search MCP servers, tools, integrations…」，带 ⌘K 快捷键）+ 右侧「Advertise」「Submit」「Switch language」「Toggle theme」「Sign In」。其下二级导航：Discover / Servers / Remote Servers / Clients / CLI / Loops / Skills / Agents / Feed。
- 主标题原文：H1「Find MCP servers, clients, and integrations in one MCP marketplace」。
- 副文案：「Use MCP.so as an MCP store, MCP server list, and curated directory for awesome MCP servers. Browse servers for Claude, IDEs, automation, databases, search, files, and developer tools.」
- CTA：hero 区两个按钮「Browse MCP servers」「Browse categories」；Trending 横幅带「Browse featured →」。
- 视觉形式：浅色温馨风格，无产品截图；hero 区是一个带柔和渐变大圆点背景的轮播横幅「Trending this week」，下方接 Sponsor 卡位、彩色分类按钮、Featured 卡片网格。

## 区块结构（自上而下逐区块列出）

1. 顶部 sponsor banner：「Sponsored by ShipAny — Agent-Native boilerplate to ship your AI product in one hour.」。
2. 顶部导航栏 + 全局搜索 + 主题/语言/登录。
3. 二级分类导航 Discover / Servers / Remote Servers / Clients / CLI / Loops / Skills / Agents / Feed。
4. Hero 轮播区「Trending this week」：副标题「What the community is installing right now」+ 5 张小图标轮播 +「Browse featured →」。
5. Sponsors：3 张 sponsor 卡片 +「Sponsor this slot」占位。
6. Top categories：5 个彩色大按钮（Developer Tools / AI & Agents / Cloud & Infrastructure / Memory & Knowledge / Media & Design）。
7. Featured servers：8 张精选 server 卡片，带「View all →」。
8. Featured clients / Featured CLI tools / Featured loops / Featured Agent Skills：多维度 featured 区块（截图中部分可见）。
9. New arrivals：最近发布 server 网格。
10. FAQ / Explore MCP Servers（页面底部）。

## 配色与气质（主色 / 底色 / 深浅 / 字体气质 / 信息密度，必须来自截图实看）

- 主色：整体浅色模式，背景为暖白/奶油色；hero 区用淡黄、淡粉、淡蓝的大圆点渐变装饰；分类按钮用柔和的蓝、紫、绿、橙底色。
- 底色：暖白接近 #FAFAF8，卡片纯白， sponsor banner 为紫-蓝渐变条。
- 深浅：默认浅色，提供「Toggle theme」切换深色。
- 字体气质：圆润无衬线，标题字重中等，整体年轻、友好、偏消费级。
- 信息密度：中低。卡片留白充足，每屏展示 3-4 个区块，适合小白快速扫描。

## 转化路径（落地 → 下载 / 安装 / 注册 / 浏览 的路径设计）

- 落地即看到「Trending this week」轮播，降低选择门槛。
- 浏览：通过二级导航切换 servers/clients/cli/loops/skills，或通过 Top categories 彩色按钮进入分类。
- 搜索：顶部搜索框 ⌘K 快捷键全局可达。
- 详情：点击卡片进入 server/client 详情页，获取安装/配置信息。
- 提交：右上角「Submit」鼓励社区提交，形成 UGC 飞轮。
- 登录：「Sign In」相对低调，未强制注册。

## 值得抄（具体到组件与手法，如"hero 把 CLI 命令做成可点击复制的芯片"，禁止"简洁大气"这类空话）

- **「Trending this week」轮播横幅**：把社区正在安装的内容做成首屏 hero，比静态 slogan 更有动态说服力，适合 yo-skill 展示「本周热门 Skill/MCP」。
- **Top categories 彩色大按钮**：5 个圆角大色块把技术分类视觉化，降低小白认知门槛。
- **多维度 Featured 区块**：servers / clients / CLI tools / loops / agent skills 分段展示，把「生态」感做出来；yo-skill 可借鉴为「Skill / MCP / 助手」分段。
- **每张卡片的「Added X days ago」时间戳**：强调新鲜度与活跃度。
- **赞助位设计**：Sponsors 区块既变现又展示生态伙伴，适合 yo-skill 未来做合作展示。
- **中文切换提示**：底部浮条「本站支持中文，要切换到中文版吗？」对国内流量友好。

## 不值得抄 / 对我们不适用

- 顶部 sponsor banner 抢占首屏：yo-skill 官网首屏应优先讲产品价值，而非第三方广告。
- 内容维度过多（Loops / Skills / Agents）：yo-skill 聚焦 Skill/MCP 管理，不需要把生态所有类型都放首页，避免稀释定位。
- 卡片信息较浅：缺少 Glama 式的质量评分， yo-skill 若做发现页应保留可信度指标。
- 过于 Marketplace 化：页面气质偏向「商店」， yo-skill 是「管理工具」，应更强调统一、安全、同步。
