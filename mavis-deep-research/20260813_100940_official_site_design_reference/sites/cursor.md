# Cursor（https://cursor.com/）

- 定位一句话：AI 原生代码编辑器 + 自主编程智能体，主打"让智能体把创意变成代码"。
- 商业模式：订阅制。Hobby 免费（有限 Agent 请求）；Individual Pro/Pro+/Ultra $20/月；Teams Standard/Premium $40/用户/月；Enterprise 定制。

## 首屏（导航结构 / 主标题原文 / 副文案 / CTA 文案与层级 / 视觉形式：产品截图？插画？纯排版？）

- 导航结构：左侧动画 Logo + CURSOR 文字；中间 Models / Product / Enterprise / Pricing / Resources；右侧 Sign in / Contact sales / 黑底 "Download" 按钮。
- 主标题原文："Cursor is your coding agent for building ambitious software."
- 副文案：无显式副标题，标题下方直接是 CTA；首屏依靠标题和一张大型产品场景图传递价值。
- CTA 文案与层级：
  1. 主按钮 "Download for Windows ↓"（黑底白字，带系统图标）
  2. 次按钮 "Request a demo →"（浅灰底）
  右上角常驻 "Download" 提供随时转化。
- 视觉形式：浅色背景 + 左对齐排版；首屏主体是一张带景深的产品场景图——同时展示 Cursor Desktop 任务面板、浏览器预览和 Cursor CLI 窗口，叠加在类似油画/风景壁纸背景上，营造"艺术感 + 工具感"的混搭。

## 配色与气质（主色 / 底色 / 深浅 / 字体气质 / 信息密度，必须来自截图实看）

- 主色：近黑（#111）用于 Logo、主按钮、标题；点缀色为柔和的橙/琥珀（"Learn about Automations" 链接）。
- 底色：暖白/米灰（#F7F7F5 左右），整体非常干净、明亮，与多数 AI 工具深色官网形成差异。
- 深浅：全站浅色，无深色模式入口；产品截图内部为浅灰编辑器界面，与页面融为一体。
- 字体气质：现代几何无衬线，标题字重中等偏大、行距宽松；正文细小写、颜色偏灰，阅读感轻松。
- 信息密度：首屏极低，靠一张大图支撑； testimonial 和 changelog 区块密度适中，但留白仍然充足，整体气质偏"精英开发者工具"。

## 转化路径（落地 → 下载 / 安装 / 注册 / 浏览 的路径设计）

- 落地首屏即见 "Download for Windows" 主按钮，同时右上角常驻 Download，降低行动成本。
- "Request a demo" 面向团队/企业，与下载按钮并列，覆盖两种决策路径。
- 定价页 Hobby 免费档作为入口，Individual/Teams/Enterprise 形成清晰的升级阶梯。
- Changelog 和名人证言作为二次说服，推动犹豫用户下载。

## 值得抄（具体到组件与手法，如"hero 把 CLI 命令做成可点击复制的芯片"，禁止"简洁大气"这类空话）

- **首屏产品场景图：多窗口层叠 + 艺术化背景**：把 IDE、CLI、浏览器预览三个界面合成一张图，既展示产品形态，又避免纯截图的枯燥；背景的油画/风景壁纸让工具站有了品牌记忆点。
- **"Add Tool or MCP" 的微文案**：在 Automations 截图里直接把 "MCP" 这个词放进按钮占位符，向开发者精准传递生态扩展能力。
- **名人证言带身份 + 金句**：每位背书人都是开发者社区中的高辨识度名字（Andrej Karpathy、Greg Brockman、Patrick Collison），引用语简短、有情绪，比企业 Logo 墙更有穿透力。
- **Changelog 作为首页固定区块**：把版本更新放在首页中段，用日期和一句话说明制造"产品进化快"的感知，适合处于快速迭代的工具产品。
- **导航栏右侧常驻 Download**：无论用户滚动到哪，右上角始终有黑色 Download 按钮，减少流失。

## 不值得抄 / 对我们不适用

- 网站整体是开发者工具语境， testimonials 和截图里的代码/CLI/IDE 对 yo-skill 的小白用户有门槛。
- 浅色暖调与 yo-skill 已定稿的 E 墨极深色系统不符，不能直接复用色彩。
- "Request a demo" + Enterprise sales 路径对 MVP 阶段过重。
- 产品图展示的是编码场景，yo-skill 需要展示的是 Skill/MCP 管理界面，需重新设计场景图。
