# Raycast（https://www.raycast.com/）

- 定位一句话：面向高级用户的 macOS/Windows 启动器 + 可扩展生产力工具集，用键盘快捷键把常用操作压到最短路径。
- 商业模式：个人版免费 Forever；Pro 订阅 $8/月（年付，月付 $10）含 AI、Cloud Sync、自定义主题；Teams Free / Teams Pro $12/用户/月（年付，月付 $15）；Enterprise 定制；另有 Advanced AI add-on +$8/月。

## 首屏（导航结构 / 主标题原文 / 副文案 / CTA 文案与层级 / 视觉形式：产品截图？插画？纯排版？）

- 导航结构：左侧 Logo，中间主导航 Store / Pro / AI / iOS / Windows / Teams / Enterprise / Blog / Pricing，右侧 Log in + 白底 "Download" 按钮。
- 主标题原文："Your shortcut to everything."
- 副文案："A collection of powerful productivity tools all within an extendable launcher. Fast, ergonomic and reliable."
- CTA 文案与层级：
  1. 主按钮 "Download for Mac"（白底高亮）
  2. 次按钮 "Download for Windows (beta)"（灰底）
  3. 辅助行 "Install via homebrew or winget | Try the new Raycast beta"
  4. 小药丸 "Meet Glaze | Learn more →"
- 视觉形式：纯深色背景 + 居中大标题排版，无产品截图，靠巨大文字和呼吸感留白建立气场；标题中 "everything." 加粗强调。

## 区块结构（自上而下逐区块列出）

1. Hero：大标题 + 副文案 + 下载按钮矩阵 + Glaze 药丸。
2. "Take shortcuts, not detours."：键盘按键阵列 + 三个关键词 Fast. / Ergonomic. / Native. / Reliable.（带 99.8% crash-free rate 数据）。
3. "It’s not about saving time."：情绪化金句，强调"不浪费感"。
4. "There’s an extension for that."：Extensions Store 入口，展示 AI、Notion Search 等插件。
5. "Your Mac just got smarter."：AI 能力模块（Quick AI、Always On ChatGPT、Automation Assistant）。
6. "Built for professionals like you."：Twitter/社区名人背书墙，含 Favorite Feature / Top Extension 证言。
7. "Don't repeat yourself."：自动化功能三联卡（Snippets / Quicklinks / Hotkeys and Aliases），配真实 UI 截图。
8. "Stay in the loop."：动态/更新/博客入口。
9. "Build the perfect tools."：开发者生态与 API 扩展。
10. "Take the short way."：底部终极 CTA，重复下载按钮。
11. Footer：产品、公司、社区、 newsletter 订阅。

## 配色与气质（主色 / 底色 / 深浅 / 字体气质 / 信息密度，必须来自截图实看）

- 主色：深黑底色（接近 #0A0A0A），纯白文字，极高对比。
- 辅色：Raycast 品牌红/橙（Logo），按钮为浅灰/白色；功能截图里出现蓝紫渐变光效。
- 深浅：全站纯深色，无浅色模式切换入口（或默认深色）。
- 字体气质：无衬线、字重中等偏粗、大标题字号极大且行距紧凑，正文细灰、字母间距略紧，整体像 Inter / Geist 现代工具字体。
- 信息密度：首屏极低，靠超大文字建立记忆点；向下滚动后功能卡密度适中，卡片间距大，图文对比清晰。

## 转化路径（落地 → 下载 / 安装 / 注册 / 浏览 的路径设计）

- 落地首页即见双平台下载按钮，Mac 主按钮优先；Windows beta 作为次按钮降低非目标用户流失。
- 顶部导航把 Store 放在最前，引导用户先"逛扩展"再下载，形成"发现价值 → 安装 App → 安装扩展"的循环。
- Pricing 入口在导航末端，免费用户可直接下载，付费意向用户自行比价。
- 底部 newsletter 作为二次触达。

## 值得抄（具体到组件与手法，如"hero 把 CLI 命令做成可点击复制的芯片"，禁止"简洁大气"这类空话）

- **Hero 大标题居中 + 双按钮矩阵**：白底主按钮 + 灰层次按钮 + 一行包管理器安装文案，把"怎么获得"一次性说完，减少用户跳出。
- **键盘按键阵列作为视觉锚点**：第二屏直接把键盘实物化铺出来，强化 "Keyboard First" 心智，不需要解释什么叫快捷键。
- **功能卡嵌真实 UI 截图**："Don't repeat yourself" 区块里每张卡都是带毛玻璃/光影的产品界面，不是抽象插画，降低理解成本。
- **名人证言带具体 Feature**：每位背书人下面写 Favorite Feature / Top Extension，把社交证明和功能卖点绑定，比单纯"好多人用"有效。
- **导航把 Store 放首位**：先让用户看到生态丰富度，再决定下载，适合有"内容/Skill 市场"属性的产品。

## 不值得抄 / 对我们不适用

- 产品本身是 launcher，首屏没有产品界面截图，对 yo-skill 这种需要解释"跨助手统一管理"的产品可能过于抽象。
- 大量 macOS 专属文案和键盘文化，对小白用户不够友好；yo-skill 的目标用户不一定理解 "command + space" 心智。
- 定价把 Advanced AI 作为 add-on，结构较复杂；yo-skill MVP 应尽量单一付费层级。
