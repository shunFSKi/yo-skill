# 1Password（https://1password.com/）

- 定位一句话：密码、密钥与访问权限的跨平台保险库，当前主推向企业/AI agent 的统一访问管理（Unified Access）。
- 商业模式：订阅制。个人 Individual $2.39/月（年付，月付 $3.99）；Families $3.59/月（年付，月付 $5.99，最多 5 人）；Teams Starter Pack $19.95/月（最多 10 人）；Business $7.99/用户/月；Enterprise 定制。另有 MSP 版与 AWS 采购通道。

## 首屏（导航结构 / 主标题原文 / 副文案 / CTA 文案与层级 / 视觉形式：产品截图？插画？纯排版？）

- 导航结构：顶部金色/沙色 announcement bar（"1Password Privileged Access: Zero standing privileges for humans and AI. Learn more →"，右侧 Sign in）。主导航白底：Logo + Business ▾ / Personal ▾ / Developers / Partners ▾ / Resources ▾ / Pricing；右侧 "Talk to sales" 文字链接 + 蓝色 "Get started free" 按钮。
- 主标题原文："Secure access for every human and AI agent"
- 副文案："Visibility and control for humans and AI agents, built on the most trusted vault for identities, credentials, and secrets."
- CTA 文案与层级：
  1. 次按钮 "Talk to sales"（白底蓝字）
  2. 主按钮 "View plans"（深蓝底白字）
  首屏右上方另有全局 "Get started free" 作为常驻转化入口。
- 视觉形式：深色渐变 Hero 背景 + 居中大标题，下方直接嵌入 1Password Admin Console 产品界面截图（显示 Dashboard / People / Groups / Vaults 等），用真实 UI 建立可信度。

## 区块结构（自上而下逐区块列出）

1. 顶部通知条：推广 Privileged Access 新产品线。
2. Hero：标题 + 副文案 + Business/Personal 切换 + 双 CTA + 产品截图。
3. "One secure platform for humans, AI agents, and machines"：四个产品模块 Enterprise Password Manager / Credential Broker / Privileged Access / SaaS Manager。
4. "1Password named a Leader for SaaS Management Platforms"：2026 Gartner Magic Quadrant 蓝色信任块，配 "Request SaaS Manager demo" / "Get the report"。
5. 客户证言：Oracle Red Bull Racing 案例 + 引用。
6. "Bring modern access under control"：总结式价值主张。
7. 信任背书：Trusted by 175,000 businesses and millions of families。
8. FAQ / 底部 CTA / Footer。

## 配色与气质（主色 / 底色 / 深浅 / 字体气质 / 信息密度，必须来自截图实看）

- 主色：1Password 品牌蓝（接近 #0056D2），用于按钮、信任块、Hero 渐变底部。
- 底色：导航与下方内容区为纯白；Hero 为深海军蓝到黑色的渐变，制造"安全/深邃"感。
- 辅色：顶部通知条为沙金/米色，作为视觉锚点但不喧宾夺主。
- 深浅：首屏深底白字形成高对比，下方内容区回归白底黑字，阅读负担低。
- 字体气质：圆润无衬线（类似 SF Pro / Inter），标题字重中等、行距宽松；正文灰度层级清晰。
- 信息密度：企业级官网密度，但首屏仍保留大量留白；产品模块以四宫格呈现，信息结构化强。

## 转化路径（落地 → 下载 / 安装 / 注册 / 浏览 的路径设计）

- 落地首屏即提供 Business / Personal 切换，先帮用户自我分流，再决定看企业方案或个人方案。
- Hero CTA "View plans" 引导到定价页；"Talk to sales" 引导销售跟进，适合高客单价企业用户。
- 全局右上角 "Get started free" 随时可注册，降低流失。
- 定价页按 Individual / Families / Teams / Business 分卡，年付默认展示，价格旁标注月付原价，制造年付优惠感知。

## 值得抄（具体到组件与手法，如"hero 把 CLI 命令做成可点击复制的芯片"，禁止"简洁大气"这类空话）

- **首屏 Business / Personal 切换开关**：直接把用户分成两条转化路径，避免企业用户和个人用户看到无关文案。
- **Hero 嵌入真实产品 Admin Console 截图**：不是 Mockup，而是带真实数据（Active people 325 / Suspended people 5）的仪表盘截图， instantly 证明产品成熟度。
- **顶部固定 announcement bar**：用一条不遮挡内容的小横幅推新产品（Privileged Access），既不破坏首屏又能引流。
- **Gartner Leader 蓝色信任块**：把第三方背书做成一个独立大色块，CTA 直接是 "Request demo" + "Get the report"，把信任转化为线索。
- **客户证言配实景图 + 职位全称**：Red Bull Racing 证言配赛车实景，署名 Head of Software Engineering for Aerodynamics，比只写 CEO 更可信。

## 不值得抄 / 对我们不适用

- 企业级/合规向话术（"Zero standing privileges"、"SaaS Management Platforms"）对 yo-skill 的小白用户过重。
- 销售主导（Talk to sales / Request demo）的转化路径不适合 MVP 阶段自助订阅产品。
- 蓝白主色虽然安全但较常见，yo-skill 已定 E 墨极黑白骨架 + 翡翠绿，不能照搬。
- 家庭版/团队版等多计划复杂度在 MVP 阶段应收敛。
