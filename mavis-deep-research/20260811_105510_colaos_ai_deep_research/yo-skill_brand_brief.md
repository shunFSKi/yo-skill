# yo-skill 品牌战略 Brief

> **定档日期**：2026-08-11
> **版本**：v0.1（待 review）
> **命名范式**：语气词 + 品类（参考 1Password / GitHub / Raycast）
> **目标用户**：AI 小白用户（不是开发者重度用户）

---

## 1. 命名来源 / Etymology

| 片段 | 含义 |
|------|------|
| **yo** | 英文招呼语，年轻人打招呼的轻松语气（"Yo, what's up?"） |
| **skill** | 技能、让 AI 学会新本事 |
| **组合** | "Yo! 给你的 AI 加个新技能" |

**范式归类**：
- 1Password：数字 + 品类
- GitHub：动作 + 品类（git + hub）
- yo-skill：语气 + 品类

**跟"小X"系列的关键差异**：
- 不跟大厂"小爱 / 小度 / 小艺 / 小布"撞
- 国际化范儿，跟 Tauri 桌面 + 1Password 范式气质匹配
- 域名可抢（`yo-skill.app` / `yoskill.app` / `yo-skill.com`）
- "yo" 自带场景感（不是抽象英文），比 Skillkit / Skillsmith 友好

**写作规范**（统一口径，避免后期改）：
- ✅ `yo-skill`
- ❌ `YoSkill` / `Yoskill` / `Yo.Skill` / `Yo Skill` / `YO-SKILL`

## 2. 一句话定位 / One-liner

备选：
- "AI 的 1Password"
- "Hey yo, AI 学新本事了"

## 3. 目标用户 Persona

| 维度 | 描述 |
|------|------|
| **身份** | AI 重度用户，但不懂 Skill / MCP / Agent 术语 |
| **工作流** | 用 Claude Code / Cursor / Codex 写代码 / 写文档 / 写文章 |
| **年龄** | 25-40 岁 |
| **收入** | 中高，对工具付费意愿强（$5-12/月可接受） |
| **痛点 1** | 换电脑后 AI 配置全没了，要重新调半天 |
| **痛点 2** | 多个 AI 工具切换麻烦（每个都要重新装 Skill） |
| **痛点 3** | 好用的 Skill 难找 / 难装（散落在 GitHub 各个角落） |
| **想要** | 跟 1Password 一样，配一次，到处用 |
| **触达渠道** | Twitter / V2EX / 即刻 / Product Hunt / 少数派 |

---

## 4. 核心隐喻 / Core Metaphor

| 概念 | 隐喻 |
|------|------|
| **Skill** | AI 的大脑（让 AI 学会新本事） |
| **MCP** | AI 的工具箱（让 AI 拥有新能力） |
| **yo-skill** | "Hey yo, 给你的 AI 装个大脑" |

**禁用隐喻**（已验证不 work）：
- ❌ 武器 / 武器库（调性太硬，"yo" 的轻松感被破坏）
- ❌ 容器 / 仓库（工程感太强，小白听不懂）
- ❌ 治理 / 资产（企业级话术，吓人）
- ❌ 市场 / 分发（电商感，跟个人工具气质不搭）
- ❌ 弹药 / 装备（游戏感，跑偏）

## 5. Slogan（首推 ①）

| # | Slogan | 调性 | 适用场景 |
|---|--------|------|----------|
| ① | **"嘿，让 AI 学会新本事"** | 直白、对标 1Password 经典文案 | 官网首屏 / ProductHunt |
| ② | "AI 大脑，随身带走" | 简洁、6 字 | 推广海报 / Twitter bio |
| ③ | "把 AI 调教好，到哪都好用" | 口语化、有"调教"拟人感 | 视频广告 / 落地页 |

**首推 ①** 的理由：句式结构跟 1Password "Passwords. Everything else can wait." 同构，简单直接，二次创作空间大。

## 6. 调性指南 / Tone of Voice

**四个核心关键词**：**轻盈 / 自信 / 不端着 / 像懂行的朋友**

**原则边界**：

| 想要 | 但不要 |
|------|--------|
| 友好 | 装嫩（二次元 / 卖萌 emoji） |
| 直接 | 冷硬（不绕弯 ≠ 不近人情） |
| 年轻 | 轻浮（懂行的 00 后同事，不是网红） |
| 专业 | 学究（大白话，不甩术语） |

**对比示例**（给文案同学参考）：

| ❌ 反例 | ✓ 正例 |
|---------|--------|
| "AI 资产治理中心，提供企业级 Skill 同步解决方案" | "Hey yo, 你的 AI 配置别再丢了" |
| "赋能开发者，释放生产力" | "hey yo, AI 配置换电脑不丢" |
| "为 AI Coding 工具打造的统一配置管理平台" | "你的 AI 工具箱，跟你走" |
| "打造下一代 AI 工作流基础设施" | "yo，AI 也能跨设备同步了" |

## 7. 视觉关键词 / Visual Direction

| 维度 | 选型 | 理由 |
|------|------|------|
| **主色** | 薄荷绿 `#00D4A8` | 清新不压眼睛；跟 1Password 紫 / Linear 紫差异化 |
| **辅色** | 暖橙 `#FF8C42` | 高亮按钮 / 关键 CTA |
| **中性色** | 墨黑 `#0F1419` + 米白 `#FAF8F5` | 文字 + 背景 |
| **中文字体** | 思源黑体（Source Han Sans） | 开源 / 跨平台 / 跟英文 Inter 字重对应 |
| **英文字体** | Inter | 现代无衬线 / 跟 Tauri 桌面气质匹配 |
| **Logo 方向** | 圆角矩形 icon（128x128px 起步）+ 嵌入 "yo" 字符（"y" 笔画简化，下方加小圆点表示"技能点"） | 桌面图标友好 / 缩到 16x16 也清晰 |
| **视觉参考** | 1Password（精致）/ Raycast（年轻）/ Linear（克制） | 三家取交集：精致 + 轻 + 干净 |

**禁用**：
- ❌ 彩色渐变（廉价感）
- ❌ 玻璃拟态（2024 风，过时）
- ❌ 过度圆角（萌系跑偏）
- ❌ AI 味的抽象光效（OpenAI 官网那种）

## 8. 副品牌策略 / Sub-brand

- **主品牌**：`yo-skill`（全小写连字符，唯一对外口径）
- **口语称呼**：`yo`（"Hey yo!" / Twitter handle `@yoskill`）
- **品类锚点**：`Skill`（搜索、SEO、用户认知）

**用法区分**：
- 产品名 / 域名 / 包名 → `yo-skill`
- 招呼语 / 吉祥物式 → `yo`
- 描述品类 → `Skill`（不缩写）

---

## 9. 差异化话术 / vs 竞品

| 竞品 | 差异点 | 话术 |
|------|--------|------|
| **1Password** | 不是密码，是 AI 配置 | "AI 的 1Password" |
| **Cindy** | 不是单 Agent 客户端，是跨 Agent 同步 | "你用 Claude / Cursor / Codex？一个 yo-skill 全搞定" |
| **SkillHub / skillhub-club** | 不是分发市场，是配置同步 | "好 Skill 难找？先把配好的带走" |
| **OpenSkills** | 不是 CLI，是 GUI | "AI 配置也能拖拖拽拽" |
| **Skillport** | 不止导入导出，是双向同步 | "不是搬家，是联通" |

**一句话差异化**：

> **"AI 工具的 1Password——一处配置，处处好用"**
