## 三句话总结

**架构**：四屏一抽屉——主屏「保险库」（AI 助手 / 大脑 / 工具箱三分组，按能力聚合）+ 详情「能力卡片」（三种类型）+ 仓库「发现」（SkillHub 式分类）+ 冲突重复页（非常驻）+ 设置抽屉四层；导航项 ≤3。

**一键**：全产品 11 个"一键点"（装进保险库 / 教给 XX / 放进工具箱 / 启停开关 / 恢复保险库 / 合并重复项 / 冲突三选一 / 更新安装助手 / 更新本事·工具 / deeplink 打开 / 立即同步），验收标准统一为"一次点击、自动兜底、结果可见"；任何需要用户碰终端、JSON、文件路径的交互都视为设计事故。

**语言**：界面禁用 Agent/Skill/MCP/server/JSON/env 等术语——Agent = AI 助手，Skill = AI 的大脑，MCP = 工具箱，yo-skill = 保险库，API key = 钥匙；安全权限转译为能力徽章（联网/读文件/要钥匙/自包含/已扫描）。
